## 题目说明（本地训练版）

判断二叉树是否满足二叉搜索树的严格大小关系。

### 官方示例

#### 示例 1

```text
root = [2,1,3]
输出 = true
```

#### 示例 2

```text
root = [5,1,4,null,null,3,6]
输出 = false
```

### 约束与训练提示

- 树中节点数目范围在[1, 10^4] 内
- -2^31 <= Node.val <= 2^31 - 1
- 不能只比较节点与直接孩子。
- 每个节点都受到祖先传递下来的上下界约束。
