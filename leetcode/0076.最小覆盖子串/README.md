## 题目说明（本地训练版）

在主字符串中找到覆盖目标串所有字符及频次的最短子串。

### 官方示例

#### 示例 1

```text
s = "ADOBECODEBANC"
t = "ABC"
输出 = "BANC"
```

#### 示例 2

```text
s = "a"
t = "a"
输出 = "a"
```

#### 示例 3

```text
s = "a"
t = "aa"
输出 = ""
```

### 约束与训练提示

- m == s.length
- n == t.length
- 1 <= m, n <= 10^5
- s 和 t 由英文字母组成
- 字符重复次数也必须满足。
- 若不存在有效窗口则返回空串。
