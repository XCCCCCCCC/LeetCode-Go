## 题目说明（本地训练版）

找出数组中出现次数超过一半的多数元素。

### 官方示例

#### 示例 1

```text
nums = [3,2,3]
输出 = 3
```

#### 示例 2

```text
nums = [2,2,1,1,1,2,2]
输出 = 2
```

### 约束与训练提示

- n == nums.length
- 1 <= n <= 5 * 10^4
- -10^9 <= nums[i] <= 10^9
- 输入保证数组中一定有一个多数元素。
- 题目保证多数元素存在。
- 摩尔投票法可在 O(1) 额外空间内完成。
