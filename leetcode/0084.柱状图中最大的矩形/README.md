## 题目说明（本地训练版）

在柱状图中选择连续柱子组成矩形，求最大面积。

### 官方示例

#### 示例 1

```text
heights = [2,1,5,6,2,3]
输出 = 10
```

#### 示例 2

```text
heights = [2,4]
输出 = 4
```

### 约束与训练提示

- 0
