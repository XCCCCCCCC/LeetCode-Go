## 题目说明（本地训练版）

数组中每个元素表示从当前位置最多可跳的距离，判断能否到达末尾。

### 官方示例

#### 示例 1

```text
nums = [2,3,1,1,4]
输出 = true
```

#### 示例 2

```text
nums = [3,2,1,0,4]
输出 = false
```

### 约束与训练提示

- 1 <= nums.length <= 10^4
- 0 <= nums[i] <= 10^5
- 遍历过程中维护当前能到达的最远位置。
- 如果当前下标已超过最远可达位置则失败。
