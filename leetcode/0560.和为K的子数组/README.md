## 题目说明（本地训练版）

统计和恰好等于目标值的连续子数组数量。

### 官方示例

#### 示例 1

```text
nums = [1,1,1]
k = 2
输出 = 2
```

#### 示例 2

```text
nums = [1,2,3]
k = 3
输出 = 2
```

### 约束与训练提示

- 1 <= nums.length <= 2 * 10^4
- -1000 <= nums[i] <= 1000
- -10^7 <= k <= 10^7
- 数组可以包含负数，不能直接使用普通滑动窗口。
- 前缀和与频次哈希可以在 O(n) 内完成。
