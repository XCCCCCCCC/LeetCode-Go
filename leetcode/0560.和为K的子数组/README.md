# [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

## 解题思路

当前实现是增量累加的双重循环：外层固定起点 `i`，内层从 `i` 向右扩展 `j`，每次执行 `sum += nums[j]` 并判断是否等于 `k`。这会恰好枚举每个连续子数组，且不依赖元素正负，时间复杂度 O(n²)、空间复杂度 O(1)。

这版作为第一版很适合建立题意模型；不能用“和小于 k 就扩右、和大于 k 就缩左”的普通滑动窗口，因为负数会破坏窗口和的单调性。二刷优化方向是前缀和频次哈希：当前前缀和为 `prefix` 时，查找 `prefix - k` 出现过几次，复杂度降为 O(n) 时间、O(n) 空间；初始必须设置 `count[0] = 1`。

核心不变量：每次内层循环结束时，`sum` 恰好等于 `nums[i..j]` 的和，`result` 已累计所有以 `i` 为起点且当前终点不超过 `j` 的命中区间。

## 边界条件

- 负数、零、重复前缀和、从下标 0 开始的子数组，以及多个答案重叠的情况都必须计数。

## 题目说明（本地训练版）

统计和恰好等于目标值的连续子数组数量。

### 官方示例

#### 示例 1

```text
nums = [1,1,1]
k = 2
输出 = 2
```

#### 示例 2

```text
nums = [1,2,3]
k = 3
输出 = 2
```

### 约束与训练提示

- 1 <= nums.length <= 2 * 10^4
- -1000 <= nums[i] <= 1000
- -10^7 <= k <= 10^7
- 数组可以包含负数，不能直接使用普通滑动窗口。
- 前缀和与频次哈希可以在 O(n) 内完成。
