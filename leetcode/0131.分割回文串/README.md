## 题目说明（本地训练版）

将字符串分割成若干子串，返回每一段都是回文串的所有分割方案。

### 官方示例

#### 示例 1

```text
s = "aab"
输出 = [["a","a","b"],["aa","b"]]
```

#### 示例 2

```text
s = "a"
输出 = [["a"]]
```

### 约束与训练提示

- 1 <= s.length <= 16
- s 仅由小写英文字母组成
- 每一次只能向后选择分割终点。
- 可预处理回文状态以避免重复判断。
