## 题目说明（本地训练版）

返回数组排序后第 k 大的元素，而不是第 k 个不同元素。

### 官方示例

#### 示例 1

```text
k = 2
nums = [3,2,1,5,6,4]
输出 = 5
```

#### 示例 2

```text
k = 4
nums = [3,2,3,1,2,4,5,5,6]
输出 = 4
```

### 约束与训练提示

- 1 <= k <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
- 数组可包含重复数字。
- 可使用快速选择或维护容量为 k 的小根堆。
