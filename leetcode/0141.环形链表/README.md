## 题目说明（本地训练版）

判断单链表中是否存在节点再次指向之前节点形成的环。

### 官方示例

#### 示例 1

```text
head = [3,2,0,-4]
pos = 1
输出 = true
```

#### 示例 2

```text
head = [1,2]
pos = 0
输出 = true
```

#### 示例 3

```text
head = [1]
pos = -1
输出 = false
```

### 约束与训练提示

- 链表中节点的数目范围是 [0, 10^4]
- -10^5 <= Node.val <= 10^5
- pos 为 -1 或者链表中的一个 有效索引 。
- 不能根据节点值判断是否相同。
- 快指针每次两步、慢指针每次一步。
