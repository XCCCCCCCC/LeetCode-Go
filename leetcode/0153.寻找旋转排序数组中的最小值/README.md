## 题目说明（本地训练版）

找出无重复升序数组旋转后的最小元素。

### 官方示例

#### 示例 1

```text
nums = [3,4,5,1,2]
输出 = 1
```

#### 示例 2

```text
nums = [4,5,6,7,0,1,2]
输出 = 0
```

#### 示例 3

```text
nums = [11,13,15,17]
输出 = 11
```

### 约束与训练提示

- n == nums.length
- 1 <= n <= 5000
- -5000 <= nums[i] <= 5000
- nums 中的所有整数 互不相同
- nums 原来是一个升序排序的数组，并进行了 1 至 n 次旋转
- 将中间值与右边界比较可判断最小值所在半区。
- 数组可能未旋转或旋转完整长度。
