## 题目说明（本地训练版）

将二叉树原地展开为只有右孩子指针的单链表，顺序与前序遍历一致。

### 官方示例

#### 示例 1

```text
root = [1,2,5,3,4,null,6]
输出 = [1,null,2,null,3,null,4,null,5,null,6]
```

#### 示例 2

```text
root = []
输出 = []
```

#### 示例 3

```text
root = [0]
输出 = [0]
```

### 约束与训练提示

- 树中结点数在范围 [0, 2000] 内
- -100
- 展开后每个节点的 left 必须为空。
- 需在覆盖指针前保存原左右子树信息。
