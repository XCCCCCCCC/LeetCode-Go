## 题目说明（本地训练版）

为每个位置计算除自身以外所有元素的乘积。

### 官方示例

#### 示例 1

```text
nums = [1,2,3,4]
输出 = [24,12,8,6]
```

#### 示例 2

```text
nums = [-1,1,0,-3,3]
输出 = [0,0,9,0,0]
```

### 约束与训练提示

- 2 <= nums.length <= 10^5
- -30 <= nums[i] <= 30
- 输入 保证 数组 answer[i] 在 32 位 整数范围内
- 不能使用除法。
- 期望线性时间，进阶要求常数额外空间。
