## 题目说明（本地训练版）

计算将一个字符串转换为另一个字符串所需的最少插入、删除和替换次数。

### 官方示例

#### 示例 1

```text
word1 = "horse"
word2 = "ros"
输出 = 3
```

#### 示例 2

```text
word1 = "intention"
word2 = "execution"
输出 = 5
```

### 约束与训练提示

- 0 <= word1.length, word2.length <= 500
- word1 和 word2 由小写英文字母组成
- 空前缀与非空前缀之间的距离需正确初始化。
- 字符相同时无需新增操作。
