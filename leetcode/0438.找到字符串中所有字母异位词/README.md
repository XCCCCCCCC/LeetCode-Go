# [438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

## 解题思路

当前 `findAnagrams_func2` 使用固定长度滑动窗口和“频次差值表”：先把 `p` 中每个字符计数减一；字符进入窗口时加一，窗口超长时移出左字符并减一。当窗口长度等于 `p.length` 且所有差值均为 0，就记录窗口左端下标。

核心不变量：窗口内字符频次减去 `p` 的字符频次后，所有差值为 0，当且仅当当前窗口是 `p` 的字母异位词。`head` 和 `tail` 都只向右移动，因此时间复杂度为 O(n·σ)，在小写字母约束下视为 O(n)，空间复杂度 O(σ)=O(1)。

当前实现保留了 `func1` 排序比较版用于对照；`func2` 是推荐复习版本。最终提交前应将推荐版本重命名为 `findAnagrams`，并让本地测试入口与函数名一致。

## 边界条件

- `p` 更长时没有答案；重复字符必须按频次比较；窗口超长时要先移除左端，再判断当前窗口。
- 新字符不在 `p` 中时必须从 0 开始计数，不能直接对 `undefined` 自增。

## 题目说明（本地训练版）

在主字符串中找出所有与目标串互为字母异位词的子串起始下标。

### 官方示例

#### 示例 1

```text
s = "cbaebabacd"
p = "abc"
输出 = [0,6]
```

#### 示例 2

```text
s = "abab"
p = "ab"
输出 = [0,1,2]
```

### 约束与训练提示

- 1 <= s.length, p.length <= 3 * 10^4
- s 和 p 仅包含小写字母
- 窗口长度固定为目标串长度。
- 返回下标顺序应与扫描顺序一致。
