## 题目说明（本地训练版）

在主字符串中找出所有与目标串互为字母异位词的子串起始下标。

### 官方示例

#### 示例 1

```text
s = "cbaebabacd"
p = "abc"
输出 = [0,6]
```

#### 示例 2

```text
s = "abab"
p = "ab"
输出 = [0,1,2]
```

### 约束与训练提示

- 1 <= s.length, p.length <= 3 * 10^4
- s 和 p 仅包含小写字母
- 窗口长度固定为目标串长度。
- 返回下标顺序应与扫描顺序一致。
