## 题目说明（本地训练版）

将包含“重复次数[子串]”结构的编码字符串还原。

### 官方示例

#### 示例 1

```text
s = "3[a]2[bc]"
输出 = "aaabcbc"
```

#### 示例 2

```text
s = "3[a2[c]]"
输出 = "accaccacc"
```

#### 示例 3

```text
s = "2[abc]3[cd]ef"
输出 = "abcabccdcdcdef"
```

#### 示例 4

```text
s = "abc3[cd]xyz"
输出 = "abccdcdcdxyz"
```

### 约束与训练提示

- 1 <= s.length <= 30
- s 由小写英文字母、数字和方括号 '[]' 组成
- s 保证是一个 有效 的输入。
- s 中所有整数的取值范围为 [1, 300]
- 编码可以多层嵌套。
- 重复次数可以由多位数字组成。
