# [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

## 解题思路

### 1. `func1` 和本题的区别

`func1` 只比较相邻元素，求的是最长连续递增子数组：

```js
nums[i - 1] < nums[i]
```

但本题求的是递增子序列，元素之间可以跳过，只要下标顺序不变。

例如：

```text
[1, 100, 2, 3] -> [1, 2, 3]
```

因此 `func1` 不能解决本题；它现在只是一个“最长连续递增段”的实现。你已经补上了循环结束时的 `max` 比较，但空数组时仍会返回 `1`，因为 `temp` 初始为 `1`。

### 2. `func2`：基础 DP

定义：

```text
dp[i] = 必须以 nums[i] 作为最后一个元素的最长递增子序列长度
```

每个元素单独都能构成长度为 1 的子序列，因此初始化：

```js
const dp = new Array(nums.length).fill(1)
```

计算第 `i` 个元素时，枚举它前面的每个 `j`：

```js
if (nums[j] < nums[i]) {
  dp[i] = Math.max(dp[i], dp[j] + 1)
}
```

如果 `nums[j] < nums[i]`，说明 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面。

### 3. 为什么允许跳过元素

循环条件是：

```js
for (let j = 0; j < i; j++)
```

它会检查 `i` 前面的所有位置，而不是只检查 `i - 1`。

例如：

```text
nums = [1, 100, 2, 3]
```

计算 `dp[2]` 时，虽然 `nums[1] = 100` 不小于 `2`，但仍会检查 `nums[0] = 1`：

```text
1 < 2
dp[2] = dp[0] + 1 = 2
```

中间的 `100` 被跳过，不影响子序列的合法性。

### 4. 为什么最后取 `result`，不能只取 `dp[n - 1]`

`dp[i]` 是“以 `nums[i]` 结尾”的答案，最长序列不一定以最后一个元素结尾。

例如：

```text
[10,9,2,5,3,7,101,18]
```

最长序列可以以 `101` 结尾，而最后一个 `18` 不一定能接在它后面。因此需要在所有 `dp[i]` 中取最大值：

```js
result = Math.max(result, dp[i])
```

### 5. 用 `[1,3,2,4]` 走一遍

```text
dp[0] = 1   // [1]
dp[1] = 2   // [1,3]
dp[2] = 2   // [1,2]
dp[3] = 3   // [1,3,4] 或 [1,2,4]
```

最终答案是 `3`。

## 核心不变量

计算 `dp[i]` 时：

```text
dp[j] 已经是以 nums[j] 结尾的正确最长长度
只要 nums[j] < nums[i]，nums[i] 就可以接到该序列后面
```

内层循环结束后：

```text
dp[i] 是所有以前元素中能够接到 nums[i] 的方案的最大值
```

## 边界条件

- 非空数组中，每个 `dp[i]` 至少为 `1`；
- 相等元素不能连接，必须使用严格比较 `nums[j] < nums[i]`；
- 最长序列不一定以最后一个元素结尾，必须取所有 `dp[i]` 的最大值；
- 空数组不是题目输入范围，但当前 `func2` 会返回 `1`，若要兼容需先判断 `nums.length === 0`；
- `func1` 统计的是连续递增子数组，不是本题要求的子序列。

时间复杂度：`O(n²)`。

空间复杂度：`O(n)`。

## 题目说明（本地训练版）

求数组中值严格递增的最长子序列长度。

### 官方示例

#### 示例 1

```text
nums = [10,9,2,5,3,7,101,18]
输出 = 4
```

#### 示例 2

```text
nums = [0,1,0,3,2,3]
输出 = 4
```

#### 示例 3

```text
nums = [7,7,7,7,7,7,7]
输出 = 1
```

### 约束与训练提示

- 1 <= nums.length <= 2500
- -10^4 <= nums[i] <= 10^4
- 你能将算法的时间复杂度降低到 O(n log(n)) 吗?
- 子序列不要求连续，但必须保持原下标顺序。
- 可使用 O(n²) DP，进阶为二分维护最小结尾。
