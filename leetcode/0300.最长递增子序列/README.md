## 题目说明（本地训练版）

求数组中值严格递增的最长子序列长度。

### 官方示例

#### 示例 1

```text
nums = [10,9,2,5,3,7,101,18]
输出 = 4
```

#### 示例 2

```text
nums = [0,1,0,3,2,3]
输出 = 4
```

#### 示例 3

```text
nums = [7,7,7,7,7,7,7]
输出 = 1
```

### 约束与训练提示

- 1 <= nums.length <= 2500
- -10^4 <= nums[i] <= 10^4
- 你能将算法的时间复杂度降低到 O(n log(n)) 吗?
- 子序列不要求连续，但必须保持原下标顺序。
- 可使用 O(n²) DP，进阶为二分维护最小结尾。
