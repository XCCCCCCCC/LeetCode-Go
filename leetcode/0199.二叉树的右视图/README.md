## 题目说明（本地训练版）

返回从二叉树右侧观察时每一层可见的节点值。

### 官方示例

#### 示例 1

```text
root = [1,2,3,null,5,null,4]
输出 = [1,3,4]
```

#### 示例 2

```text
root = [1,2,3,4,null,null,null,5]
输出 = [1,3,4,5]
```

#### 示例 3

```text
root = [1,null,3]
输出 = [1,3]
```

#### 示例 4

```text
root = []
输出 = []
```

### 约束与训练提示

- 二叉树的节点个数的范围是 [0,100]
- -100 <= Node.val <= 100
- 可层序遍历并取每层最后节点。
- 也可优先访问右子树并记录每个深度的首个节点。
