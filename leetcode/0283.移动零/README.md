# [283. 移动零](https://leetcode.cn/problems/move-zeroes/)

## 解题思路

当前实现使用慢快双指针并原地交换：`quick` 扫描整个数组，`slow` 指向下一个应该写入非零元素的位置。遇到非零值就与 `nums[slow]` 交换，然后 `slow++`。

核心不变量：任意时刻，`[0, slow)` 已经是保持原相对顺序的非零元素；`[slow, quick)` 中的元素已经处理完成，剩余位置最终由零填充。每个元素只被 `quick` 扫描一次，时间 O(n)、额外空间 O(1)。

当前版本的交换写法清晰但可能产生不必要的自交换；二刷可改成“先写非零，再从 `slow` 到末尾填 0”，减少交换。

## 边界条件

- 空数组、全零数组、无零数组和零散零值都应保持正确顺序。

## 题目说明（本地训练版）

在原数组上把所有零移到末尾，并保持非零元素的相对顺序。

### 官方示例

#### 示例 1

```text
nums = [0,1,0,3,12]
输出 = [1,3,12,0,0]
```

#### 示例 2

```text
nums = [0]
输出 = [0]
```

### 约束与训练提示

- 1 <= nums.length <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1
- 必须原地修改输入数组。
- 进阶目标是减少写入或交换次数。
