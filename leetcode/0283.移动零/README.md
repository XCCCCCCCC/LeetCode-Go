## 题目说明（本地训练版）

在原数组上把所有零移到末尾，并保持非零元素的相对顺序。

### 官方示例

#### 示例 1

```text
nums = [0,1,0,3,12]
输出 = [1,3,12,0,0]
```

#### 示例 2

```text
nums = [0]
输出 = [0]
```

### 约束与训练提示

- 1 <= nums.length <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1
- 必须原地修改输入数组。
- 进阶目标是减少写入或交换次数。
