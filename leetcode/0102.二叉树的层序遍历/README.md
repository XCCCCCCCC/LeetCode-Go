## 题目说明（本地训练版）

按层从上到下返回二叉树节点值，每一层单独形成一个数组。

### 官方示例

#### 示例 1

```text
root = [3,9,20,null,null,15,7]
输出 = [[3],[9,20],[15,7]]
```

#### 示例 2

```text
root = [1]
输出 = [[1]]
```

#### 示例 3

```text
root = []
输出 = []
```

### 约束与训练提示

- 树中节点数目在范围 [0, 2000] 内
- -1000 <= Node.val <= 1000
- 队列中保存待访问节点。
- 每轮先记录当前队列长度以确定本层范围。
