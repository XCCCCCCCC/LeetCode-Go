# [搜索插入位置](https://leetcode.cn/problems/search-insert-position/)

<!-- hot100-problem:start -->
## 题目说明（本地训练版）

在升序且无重复元素的数组中查找目标值，不存在时返回应插入的位置。

### 官方示例

#### 示例 1

```text
nums = [1,3,5,6]
target = 5
输出 = 2
```

#### 示例 2

```text
nums = [1,3,5,6]
target = 2
输出 = 1
```

#### 示例 3

```text
nums = [1,3,5,6]
target = 7
输出 = 4
```

### 约束与训练提示

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i] <= 10^4
- nums 为 无重复元素 的 升序 排列数组
- -10^4 <= target <= 10^4
- 返回的是保持升序的左边界位置。
- 期望 O(log n) 时间。

