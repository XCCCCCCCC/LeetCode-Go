# [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)

## 解题思路

先按照每个区间的左端点升序排序。排序后，当前区间只需要与结果数组中的最后一个区间比较：

1. 如果结果数组为空，或者最后一个区间的右端点小于当前区间的左端点，说明两者不重叠，直接把当前区间加入结果；
2. 否则说明两个区间存在重叠，将最后一个区间的右端点更新为两个右端点的最大值。

```text
last[1] < current[0]   不重叠，加入 current
last[1] >= current[0]  存在重叠，更新 last[1]
```

之所以只需要比较最后一个区间，是因为所有区间已经按左端点排序，结果数组中更早的区间已经完成合并，而且与最后一个区间互不重叠。

核心不变量：每轮遍历结束后，`result` 中的区间按照左端点有序且互不重叠；最后一个区间表示所有已处理区间中最靠右、仍可能与后续区间合并的结果。

排序需要 O(n log n)，遍历需要 O(n)，因此总时间复杂度为 O(n log n)；结果数组最多保存 n 个区间，空间复杂度为 O(n)。

## 边界条件

- 只有一个区间时直接得到原区间。
- 端点相等也属于重叠，例如 `[1,4]` 和 `[4,5]` 应合并为 `[1,5]`。
- 一个区间可能完全包含另一个区间，更新右端点时必须使用 `Math.max`。
- 多个区间可能连续合并，例如 `[[1,4],[2,3],[3,6]]` 最终得到 `[[1,6]]`。

## 题目说明（本地训练版）

合并所有存在重叠的区间，返回互不重叠的覆盖结果。

### 官方示例

#### 示例 1

```text
intervals = [[1,3],[2,6],[8,10],[15,18]]
输出 = [[1,6],[8,10],[15,18]]
```

#### 示例 2

```text
intervals = [[1,4],[4,5]]
输出 = [[1,5]]
```

#### 示例 3

```text
intervals = [[4,7],[1,4]]
输出 = [[1,7]]
```

### 约束与训练提示

- 1 <= intervals.length <= 10^4
- intervals[i].length == 2
- 0 <= start_i <= end_i <= 10^4
- 通常先按区间起点排序。
- 相交时需更新当前区间的最右端。
