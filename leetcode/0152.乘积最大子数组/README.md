## 题目说明（本地训练版）

求乘积最大的非空连续子数组。

### 官方示例

#### 示例 1

```text
nums = [2,3,-2,4]
输出 = 6
```

#### 示例 2

```text
nums = [-2,0,-1]
输出 = 0
```

### 约束与训练提示

- 1 <= nums.length <= 2 * 10^4
- -10 <= nums[i] <= 10
- nums 的任何子数组的乘积都 保证 是一个 32-位 整数
- 负数会让最大与最小乘积互换角色。
- 每个位置需同时维护最大和最小结尾乘积。
