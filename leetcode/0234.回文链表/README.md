# [234. 回文链表](https://leetcode.cn/problems/palindrome-linked-list/)

## 解题思路

### 先把题目翻译成容易操作的形式

回文的意思是：从左到右读，和从右到左读完全一样。

```text
[1,2,2,1]：正着是 1,2,2,1，反着也是 1,2,2,1，属于回文
[1,2]：正着是 1,2，反着是 2,1，不属于回文
```

链表只能通过 `next` 从前往后走，不能像数组一样直接访问最后一个节点，也没有 `prev` 指针。因此当前解法先完成一次链表遍历，把每个节点的 `val` 放入数组，再把问题交给数组处理。

这里不是把链表“转成一个数字”，而是只复制节点值：

```text
链表：1 → 2 → 2 → 1 → null
数组：[1, 2, 2, 1]
```

节点本身没有被复制或修改，数组只是帮助我们获得下标访问能力。

### 当前写法：链表转数组，再从两端比较

第一段循环负责遍历链表：

```js
let temp = []
while (head !== null) {
  temp.push(head.val)
  head = head.next
}
```

其中：

```text
temp：按链表顺序保存所有节点值
head：当前正在访问的节点；移动到 head.next 后继续向后走
```

链表遍历结束后，使用两个下标从数组两端向中间靠拢：

```js
for (let i = 0, j = temp.length - 1; i < j; i++, j--) {
  if (temp[i] !== temp[j]) {
    return false
  }
}
return true
```

每一轮都比较一对对称位置：

```text
第1轮：比较第一个和最后一个
第2轮：比较第二个和倒数第二个
……
```

只要发现一对不相同，就可以立刻确定不是回文；如果所有对称位置都相同，才返回 `true`。

核心不变量：在循环开始时，`i` 和 `j` 外侧的所有位置都已经确认相等；循环只需要继续检查尚未比较的中间区域。

假设链表有 `n` 个节点：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

时间是 `O(n)`：第一次遍历链表一次，第二次最多比较数组的一半，合起来仍然是线性时间。空间是 `O(n)`：数组保存了 `n` 个节点值。

### 二刷方向：快慢指针 + 反转后半段

题目要求的进阶方案是额外空间 `O(1)`。核心仍然是比较前半段和后半段，只是不用数组保存，而是：

1. 用快慢指针找到链表中点：慢指针每次走一步，快指针每次走两步；
2. 反转后半段链表，使后半段也可以从前往后遍历；
3. 从头节点和反转后的后半段头节点同时向后走，逐个比较 `val`；
4. 如果需要保持输入链表不变，再把后半段反转回来。

例如：

```text
原链表：1 → 2 → 2 → 1
分成：  1 → 2    和    2 → 1
比较：  1 == 1，2 == 2
```

奇数长度时，中间节点没有对应的比较对象，可以跳过：

```text
1 → 2 → 3 → 2 → 1
左半段：1 → 2
中间：  3（不用比较）
右半段：2 → 1
```

这条进阶路线的难点是“找中点”和“反转后半段”的指针操作，建议在掌握当前数组解法后再单独实现。

## 边界条件

- 单节点链表：只有一个值，天然是回文。
- 两节点链表：只有两个值，必须相等才是回文。
- 首尾值不同：可以在第一次比较时直接返回 `false`。
- 所有值都相同：比较完整个数组后返回 `true`。
- 题目约束中的空链表不作为输入；如果写通用版本，`head === null` 也应返回 `true`。
- 当前代码只修改了局部变量 `head`，没有改变原链表结构。

## 题目说明（本地训练版）

判断单链表中的值从前往后和从后往前是否相同。

### 官方示例

#### 示例 1

```text
head = [1,2,2,1]
输出 = true
```

#### 示例 2

```text
head = [1,2]
输出 = false
```

### 约束与训练提示

- 链表中节点数目在范围[1, 10^5] 内
- 0 <= Node.val <= 9
- 进阶要求线性时间和常数额外空间。
- 可通过快慢指针找到中点后反转后半段。
