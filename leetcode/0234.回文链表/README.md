## 题目说明（本地训练版）

判断单链表中的值从前往后和从后往前是否相同。

### 官方示例

#### 示例 1

```text
head = [1,2,2,1]
输出 = true
```

#### 示例 2

```text
head = [1,2]
输出 = false
```

### 约束与训练提示

- 链表中节点数目在范围[1, 10^5] 内
- 0 <= Node.val <= 9
- 进阶要求线性时间和常数额外空间。
- 可通过快慢指针找到中点后反转后半段。
