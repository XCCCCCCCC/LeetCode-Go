## 题目说明（本地训练版）

判断一棵二叉树是否关于中心轴镜像对称。

### 官方示例

#### 示例 1

```text
root = [1,2,2,3,4,4,3]
输出 = true
```

#### 示例 2

```text
root = [1,2,2,null,3,null,3]
输出 = false
```

### 约束与训练提示

- 树中节点数目在范围 [1, 1000] 内
- -100 <= Node.val <= 100
- 需要成对比较左子树的左侧与右子树的右侧。
- 空节点的成对情况必须一致。
