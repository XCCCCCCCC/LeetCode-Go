## 题目说明（本地训练版）

在 n×n 棋盘上放置 n 个皇后，返回所有互不攻击的布局。

### 官方示例

#### 示例 1

```text
n = 4
输出 = [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
```

#### 示例 2

```text
n = 1
输出 = [["Q"]]
```

### 约束与训练提示

- 1 <= n <= 9
- 每行、每列以及两类对角线最多一个皇后。
- 逐行放置可大幅简化状态。
