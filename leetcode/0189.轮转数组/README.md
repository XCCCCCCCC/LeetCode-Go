## 题目说明（本地训练版）

将数组所有元素向右轮转指定步数，并原地修改数组。

### 官方示例

#### 示例 1

```text
nums = [1,2,3,4,5,6,7]
k = 3
输出 = [5,6,7,1,2,3,4]
```

#### 示例 2

```text
nums = [-1,-100,3,99]
k = 2
输出 = [3,99,-1,-100]
```

### 约束与训练提示

- 1 <= nums.length <= 10^5
- -2^31 <= nums[i] <= 2^31 - 1
- 0 <= k <= 10^5
- 尽可能想出更多的解决方案，至少有 三种 不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 O(1) 的 原地 算法解决这个问题吗？
- 步数可能大于数组长度。
- 可通过取模简化实际旋转步数。
