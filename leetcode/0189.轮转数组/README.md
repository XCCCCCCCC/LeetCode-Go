# [189. 轮转数组](https://leetcode.cn/problems/rotate-array/)

## 解题思路

首先把轮转次数缩小到有效范围：

```js
k %= nums.length
```

数组长度为 `n` 时，向右轮转 `n` 次会回到原状，因此真正需要移动的次数只有 `k % n`。

### 思路一：截取尾部并插入头部

当前写法使用 `splice` 删除并返回数组最后 `k` 个元素，再使用 `unshift` 把这些元素插入数组头部：

```js
nums.unshift(...nums.splice(nums.length - k))
```

例如：

```text
nums = [1,2,3,4,5,6,7], k = 3

splice 后：
原数组       = [1,2,3,4]
被截取的部分 = [5,6,7]

unshift 后：
nums = [5,6,7,1,2,3,4]
```

该方案直接修改了 `nums`，时间复杂度为 O(n)。但 `splice` 会创建包含 `k` 个元素的新数组，因此辅助空间复杂度为 O(k)，最坏情况下为 O(n)，不属于严格的 O(1) 额外空间方案。

### 思路二：三次翻转，辅助空间 O(1)

把原数组分成两部分：

```text
A = 前 n - k 个元素
B = 后 k 个元素
```

原数组是：

```text
A + B
```

向右轮转 `k` 位的目标是：

```text
B + A
```

可以通过三次原地翻转完成：

1. 翻转整个数组，得到 `reverse(B) + reverse(A)`；
2. 翻转前 `k` 个元素，把 `reverse(B)` 恢复为 `B`；
3. 翻转剩余 `n - k` 个元素，把 `reverse(A)` 恢复为 `A`。

以 `[1,2,3,4,5,6,7]`、`k = 3` 为例：

```text
原数组：          [1,2,3,4,5,6,7]
整体翻转：        [7,6,5,4,3,2,1]
翻转前 3 个：     [5,6,7,4,3,2,1]
翻转剩余部分：    [5,6,7,1,2,3,4]
```

对应实现结构：

```js
var rotate_func2 = function (nums, k) {
  k %= nums.length

  const reverse = (left, right) => {
    while (left < right) {
      const temp = nums[left]
      nums[left] = nums[right]
      nums[right] = temp
      left++
      right--
    }
  }

  reverse(0, nums.length - 1)
  reverse(0, k - 1)
  reverse(k, nums.length - 1)
}
```

三次翻转虽然总共进行了多段扫描，但每个元素只被处理常数次，因此时间复杂度仍是 O(n)。整个过程只使用下标和一个临时变量，辅助空间复杂度为 O(1)。

核心不变量：每次 `reverse(left, right)` 结束后，指定闭区间内的元素顺序完全反转，区间外的元素保持不变；三次翻转最终把 `A + B` 转换成 `B + A`。

## 边界条件

- `k = 0` 时数组保持不变。
- `k = nums.length` 或其倍数时，取模后等价于轮转 0 次。
- `k > nums.length` 时必须先取模。
- 单元素数组无论轮转多少次都保持不变。
- 题目保证数组非空，因此 `k %= nums.length` 不会发生除以 0。

## 题目说明（本地训练版）

将数组所有元素向右轮转指定步数，并原地修改数组。

### 官方示例

#### 示例 1

```text
nums = [1,2,3,4,5,6,7]
k = 3
输出 = [5,6,7,1,2,3,4]
```

#### 示例 2

```text
nums = [-1,-100,3,99]
k = 2
输出 = [3,99,-1,-100]
```

### 约束与训练提示

- 1 <= nums.length <= 10^5
- -2^31 <= nums[i] <= 2^31 - 1
- 0 <= k <= 10^5
- 尽可能想出更多的解决方案，至少有 三种 不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 O(1) 的 原地 算法解决这个问题吗？
- 步数可能大于数组长度。
- 可通过取模简化实际旋转步数。
