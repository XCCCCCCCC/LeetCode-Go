# [160. 相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/)

## 解题思路

### 先理解题目中的“相交”

链表节点不只保存数值，还保存了指向下一个节点的引用：

```js
{
  val: 8,
  next: 下一个节点
}
```

因此，两个节点的 `val` 相同，不代表它们是同一个节点：

```js
nodeA.val === nodeB.val // 只比较数值
nodeA === nodeB         // 比较是否引用同一个节点对象
```

本题判断的是第二种情况。只看题目展示的数组，只能看到节点值，看不到引用关系；示例中的 `skipA` 和 `skipB` 是为了说明两条链表从哪个节点开始共用同一段链表。

例如：

```text
A：4(A4) → 1(A1) ┐
                  8(C8) → 4(C4) → 5(C5)
B：5(B5) → 6(B6) → 1(B1) ┘
```

`A1` 和 `B1` 的值虽然都是 `1`，但它们是两个不同的节点；`C8` 在 A 中是第三个节点，在 B 中是第四个节点，但双方指向的是同一个节点对象，所以交点是 `C8`。

### 当前写法：哈希集合记录节点引用

当前解法分为两次遍历：

1. 遍历链表 A，把经过的每一个节点对象放进 `Set`；
2. 遍历链表 B，检查当前节点是否已经存在于 `Set`；
3. 第一次找到已经存在的节点时，这个节点就是两条链表的第一个交点；
4. 如果 B 遍历结束仍未找到，应返回 `null`。

`Set` 中保存的是节点对象的引用，而不是节点的值。因此，即使两个节点的 `val` 都是 `1`，只要它们不是同一个对象，`result.has(temp)` 就仍然是 `false`。

可以把当前代码中的变量理解为：

```text
result：记录链表 A 中出现过的所有节点引用
temp：当前正在访问的节点
```

核心不变量：遍历 B 时，`result` 始终保存着链表 A 的全部节点；因此 B 中第一个被 `result` 命中的节点，就是两条链表开始共用的第一个节点。

假设链表 A 长度为 `m`，链表 B 长度为 `n`：

```text
时间复杂度：O(m + n)
空间复杂度：O(m)
```

### 二刷方向：双指针消除长度差

哈希集合的思路直观，适合第一次理解引用。二刷时可以尝试空间复杂度为 `O(1)` 的双指针写法：

```js
let pA = headA
let pB = headB

while (pA !== pB) {
  pA = pA === null ? headB : pA.next
  pB = pB === null ? headA : pB.next
}

return pA
```

两个指针分别走下面两条完整路线：

```text
pA：链表 A + 链表 B
pB：链表 B + 链表 A
```

如果 A、B 在交点前的长度不同，交换起点后，两者走过的总路程都会变成 `m + n`，原来的长度差就被抵消了。它们最终会：

- 在第一个公共节点相遇；
- 或者在没有交点时同时变成 `null`。

这个方法的重点不是“追赶”，而是让两个指针走完相同的总路程。

## 边界条件

- 两条链表没有交点：遍历结束后返回 `null`，不能依赖 JavaScript 默认返回的 `undefined`。
- 两个头节点就是同一个对象：交点就是 `headA`。
- 两条链表中存在相同数值：不能比较 `val`，必须比较节点引用。
- 只有最后一个节点相同：最后一个节点仍然是合法交点。
- 只要某个节点相同，该节点之后的整段链表都会相同，因为同一个节点只有同一个 `next`。

## 题目说明（本地训练版）

找到两条单链表开始共用节点的第一个交点，无交点时返回空。

### 官方示例

#### 示例 1

```text
intersectVal = 8
listA = [4,1,8,4,5]
listB = [5,6,1,8,4,5]
skipA = 2
skipB = 3
输出 = 8
```

#### 示例 2

```text
intersectVal = 2
listA = [1,9,1,2,4]
listB = [3,2,4]
skipA = 3
skipB = 1
输出 = 2
```

#### 示例 3

```text
intersectVal = 0
listA = [2,6,4]
listB = [1,5]
skipA = 3
skipB = 2
输出 = null
```

### 约束与训练提示

- listA 中节点数目为 m
- listB 中节点数目为 n
- 1 <= m, n <= 3 * 10^4
- 1 <= Node.val <= 10^5
- 0 <= skipA <= m
- 0 <= skipB <= n
- 如果 listA 和 listB 没有交点，intersectVal 为 0
- 如果 listA 和 listB 有交点，intersectVal == listA[skipA] == listB[skipB]
- 比较的是节点引用而不是节点值。
- 解法不应改变链表结构。
