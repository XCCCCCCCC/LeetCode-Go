# [118. 杨辉三角](https://leetcode.cn/problems/pascals-triangle/)

## 解题思路

你的代码是标准的逐行构造：

```text
第 0 行：[1]
第 1 行：[1, 1]
第 2 行：[1, 2, 1]
第 3 行：[1, 3, 3, 1]
```

每行都有两个规律：首尾一定是 1，中间位置等于上一行左上方与右上方之和。

外层循环负责生成每一行：

```js
const row = new Array(i + 1).fill(1)
```

它同时创建长度为 `i + 1` 的当前行，并把首尾位置初始化为 `1`。

内层循环只计算中间位置：

```js
for (let j = 1; j < i; j++) {
  row[j] = result[i - 1][j - 1] + result[i - 1][j]
}
```

第 `i` 行的中间下标正好是 `1` 到 `i - 1`，所以不会修改首尾。生成 `[1,3,3,1]` 时，上一行 `[1,2,1]` 会得到 `1 + 2 = 3` 和 `2 + 1 = 3`。

当 `i = 0` 或 `i = 1` 时，`j < i` 不成立，不会访问不存在的上一行；从 `i = 2` 开始，`result[i - 1]` 已经存在。

## 动态规划视角

可以定义：

```text
dp[i][j]：第 i 行第 j 列的数字
```

状态转移：

```text
dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
```

边界状态是每行首尾的 1。你的 `result` 保存已经生成的行，因此可以用上一行计算当前行，这就是二维 DP 的基本形式。

## 核心不变量

生成第 `i` 行时：

```text
result 已经保存 0 到 i - 1 行
当前 row 长度为 i + 1
row 首尾已经是 1
内层循环只填充 row 的中间位置
```

当前行完成后才加入 `result`，供下一行使用。

## 边界条件

- `numRows = 0`：返回空数组；
- `numRows = 1`：返回 `[[1]]`；
- 第 0 行和第 1 行没有中间元素，内层循环不会执行；
- 当前行首尾始终为 1。

时间复杂度：`O(numRows²)`。

空间复杂度：`O(numRows²)`，因为返回结果本身包含所有行。

## 题目说明（本地训练版）

生成杨辉三角的前指定行数。

### 官方示例

#### 示例 1

```text
numRows = 5
输出 = [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

#### 示例 2

```text
numRows = 1
输出 = [[1]]
```

### 约束与训练提示

- 1 <= numRows <= 30
- 每行首尾均为一。
- 内部元素等于上一行对应位置左右两数之和。
