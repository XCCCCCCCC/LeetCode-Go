## 题目说明（本地训练版）

生成杨辉三角的前指定行数。

### 官方示例

#### 示例 1

```text
numRows = 5
输出 = [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

#### 示例 2

```text
numRows = 1
输出 = [[1]]
```

### 约束与训练提示

- 1 <= numRows <= 30
- 每行首尾均为一。
- 内部元素等于上一行对应位置左右两数之和。
