# [73. 矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/)

## 解题思路

设矩阵有 `m` 行、`n` 列。题目的关键是：不能在发现 0 后立刻把整行整列改成 0，否则新写入的 0 会被误认为是原始 0，导致更多行列被错误清零。

### 当前版本：行列布尔标记

当前实现使用两个一维布尔数组：

```js
tempX[i] = true // 第 i 行需要清零
tempY[j] = true // 第 j 列需要清零
```

算法分两遍：

1. 第一遍只读取原矩阵，发现 `matrix[i][j] === 0` 时标记第 `i` 行和第 `j` 列；
2. 第二遍再次遍历矩阵，只要当前行或当前列被标记，就把元素改为 0。

核心不变量：第一遍结束后，`tempX` 和 `tempY` 完整记录了原始矩阵中的所有 0 所影响的行和列；第二遍只依据标记修改，不再依赖已经被修改的矩阵内容。

把原来的 `includes` 查找改为布尔数组下标访问后，每次标记和查询都是 O(1)，因此当前版本的复杂度为：

```text
时间复杂度：O(mn)
辅助空间复杂度：O(m + n)
```

这比“用数组保存行列编号，再在每个单元格上调用 `includes`”更好：后者的查找本身是线性的，最坏可能达到 O(mn(m+n))。

### 进阶版本：用第一行和第一列存放标记

题目要求进一步做到常量额外空间，可以复用矩阵本身的第一行和第一列：

```text
matrix[i][0] = 0  表示第 i 行需要清零
matrix[0][j] = 0  表示第 j 列需要清零
```

但第一行和第一列既是存放标记的位置，也可能原本就包含 0，所以需要额外保存两个布尔变量：

```text
firstRowZero：第一行原本是否有 0
firstColZero：第一列原本是否有 0
```

推荐处理顺序：

1. 先单独检查第一行和第一列；
2. 从 `matrix[1][1]` 开始扫描内部区域，发现 0 时标记对应的第一列和第一行；
3. 根据第一行、第一列的标记，把内部区域置 0；
4. 最后根据两个布尔变量处理第一行和第一列。

这样不需要新建行数组或列数组：

```text
时间复杂度：O(mn)
辅助空间复杂度：O(1)
```

## 边界条件

- 没有 0：矩阵保持不变。
- 只有一个 0：只清零对应的一行和一列。
- 多个 0：所有被影响的行和列都要清零。
- 0 在第一行或第一列：使用第一行第一列标记法时必须用额外布尔变量保护原始状态。
- 单行或单列矩阵：仍然按照同样的标记规则处理。

## 题目说明（本地训练版）

若矩阵某个元素为零，将其所在整行和整列都设为零。

### 官方示例

#### 示例 1

```text
matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出 = [[1,0,1],[0,0,0],[1,0,1]]
```

#### 示例 2

```text
matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出 = [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

### 约束与训练提示

- m == matrix.length
- n == matrix[0].length
- 1 <= m, n <= 200
- -2^31 <= matrix[i][j] <= 2^31 - 1
- 一个直观的解决方案是使用 O(mn) 的额外空间，但这并不是一个好的解决方案。
- 一个简单的改进方案是使用 O(m + n) 的额外空间，但这仍然不是最好的解决方案。
- 你能想出一个仅使用常量空间的解决方案吗？
- 必须原地修改矩阵。
- 不能让新写入的零影响原始标记判断。
