## 题目说明（本地训练版）

在非负数网格中只向右或向下移动，求从左上到右下的最小路径和。

### 官方示例

#### 示例 1

```text
grid = [[1,3,1],[1,5,1],[4,2,1]]
输出 = 7
```

#### 示例 2

```text
grid = [[1,2,3],[4,5,6]]
输出 = 12
```

### 约束与训练提示

- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 200
- 0 <= grid[i][j] <= 200
- 每个格子的最优值来自上方和左方中较小者。
- 需单独初始化第一行和第一列。
