## 题目说明（本地训练版）

求二叉树中任意两个节点之间最长路径所经过的边数。

### 官方示例

#### 示例 1

```text
root = [1,2,3,4,5]
输出 = 3
```

#### 示例 2

```text
root = [1,2]
输出 = 1
```

### 约束与训练提示

- 树中节点数目在范围 [1, 10^4] 内
- -100 <= Node.val <= 100
- 最长路径不一定经过根节点。
- 递归返回单边深度，同时用左右深度更新答案。
