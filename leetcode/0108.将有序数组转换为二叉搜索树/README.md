## 题目说明（本地训练版）

将严格升序数组转换为一棵高度平衡的二叉搜索树。

### 官方示例

#### 示例 1

```text
nums = [-10,-3,0,5,9]
输出 = [0,-3,9,-10,null,5]
```

#### 示例 2

```text
nums = [1,3]
输出 = [3,1]
```

### 约束与训练提示

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i] <= 10^4
- nums 按 严格递增 顺序排列
- 多种树形均可能有效。
- 选择区间中点作为根可保持平衡。
