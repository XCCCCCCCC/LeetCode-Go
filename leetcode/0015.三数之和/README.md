# [三数之和](https://leetcode.cn/problems/3sum/)

给你一个包含 n 个整数的数组 nums，判断 nums 中是否存在三个元素 a，b，c ，使得 a + b + c = 0 ？请你找出所有和为 0 且不重复的三元组。

示例1：
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

示例2：
```
输入：nums = []
输出：[]
```

示例3：
```
输入：nums = [0]
输出：[]
```

## 解题思路

当前主版本是“排序 + 固定一个数 + 左右双指针”。排序后，对固定下标 `cur`，窗口 `[left, right]` 始终位于 `cur` 右侧：

- 三数之和小于 0，`left++`，寻找更大的数；
- 三数之和大于 0，`right--`，寻找更小的数；
- 找到 0 后同时收缩，并跳过相邻重复值。

核心不变量：数组已经有序，且每次循环都保持 `cur < left < right`；移动指针后不会漏掉可能的解。`cur`、`left`、`right` 三个层次的去重共同保证结果不重复。

当前文件保留了三个练习版本：`threeSum_func1` 是双指针版本，`threeSum_func2` 是便于理解但为 O(n³) 的暴力版本，`threeSum_func3` 是当前本地测试入口。最终提交前应保留或重命名为力扣要求的 `threeSum`。

## 题目说明（本地训练版）

找出数组中所有和为零的不重复三元组。

### 官方示例

#### 示例 1

```text
nums = [-1,0,1,2,-1,-4]
输出 = [[-1,-1,2],[-1,0,1]]
```

#### 示例 2

```text
nums = [0,1,1]
输出 = []
```

#### 示例 3

```text
nums = [0,0,0]
输出 = [[0,0,0]]
```

### 约束与训练提示

- 3 <= nums.length <= 3000
- -10^5 <= nums[i] <= 10^5
- 同一下标不能重复使用。
- 结果集中不能出现重复组合。
