## 题目说明（本地训练版）

不能偷窃相邻房屋，求从给定金额中可获得的最大总金额。

### 官方示例

#### 示例 1

```text
nums = [1,2,3,1]
输出 = 4
```

#### 示例 2

```text
nums = [2,7,9,3,1]
输出 = 12
```
