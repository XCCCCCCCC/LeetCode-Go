# [198. 打家劫舍](https://leetcode.cn/problems/house-robber/)

## 解题思路

### 1. 每间房子只有两个选择

处理第 `i` 间房子时，只有两种情况：

```text
不偷第 i 间：沿用前 i - 1 间房子的最大金额
偷第 i 间：不能偷第 i - 1 间，只能加上前 i - 2 间的最大金额
```

因此定义：

```text
dp[i] = 考虑下标 0 到 i 的房子时，能够获得的最大金额
```

状态转移：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

### 2. 你的代码逐行解释

```js
let result = new Array(nums.length)
```

`result[i]` 就是 `dp[i]`，保存考虑到第 `i` 间房子时的最大金额。

```js
let prev1 = i - 1 >= 0 ? result[i - 1] : 0
let prev2 = i - 2 >= 0 ? result[i - 2] : 0
```

这里分别取出：

```text
prev1：不偷当前房子时的收益
prev2：偷当前房子时，前面能够使用的收益
```

```js
result[i] = Math.max(prev1, prev2 + nums[i])
```

在“偷”和“不偷”之间取较大值。

你的代码在官方测试和边界案例中均通过，状态转移是正确的。

### 3. 用 `[2,7,9,3,1]` 走一遍

| 下标 `i` | 金额 | 不偷当前 | 偷当前 | `result[i]` |
|---:|---:|---:|---:|---:|
| 0 | 2 | 0 | 2 | 2 |
| 1 | 7 | 2 | 7 | 7 |
| 2 | 9 | 7 | 11 | 11 |
| 3 | 3 | 11 | 10 | 11 |
| 4 | 1 | 11 | 12 | 12 |

最终答案是 `12`，对应偷第 0、2、4 间房子。

### 4. 为什么这是动态规划

到第 `i` 间房子时，后续只需要知道：

```text
前一间的最大收益
前两间的最大收益
```

不需要知道之前具体偷了哪些房子。过去的复杂选择已经被 `dp[i - 1]` 和 `dp[i - 2]` 总结成最有用的结果。

这就是 DP 的典型特点：

```text
当前状态依赖更小状态
更小状态的结果可以重复复用
```

### 5. 空间压缩

你的 `result` 数组写法已经是正确 DP，但空间复杂度为 `O(n)`。因为计算当前状态只需要前两个状态，可以压缩成两个变量：

```js
const rob_func2 = (nums) => {
  let prev2 = 0
  let prev1 = 0

  for (const money of nums) {
    const current = Math.max(prev1, prev2 + money)
    prev2 = prev1
    prev1 = current
  }

  return prev1
}
```

这里使用两个初始 `0`，可以自然处理空数组、单元素和双元素情况：

```text
prev2：处理当前房子前的 dp[i - 2]
prev1：处理当前房子前的 dp[i - 1]
current：处理当前房子后的 dp[i]
```

## 核心不变量

处理第 `i` 间房子前：

```text
result[i - 1] 是前 i 间房子的最大收益
result[i - 2] 是前 i - 1 间房子的最大收益
```

处理第 `i` 间房子后：

```text
result[i] 是前 i + 1 间房子的最大收益
```

## 边界条件

- 只有一间房：直接偷它，答案是 `nums[0]`；
- 两间房：只能选择金额较大的一间；
- 连续小金额不代表一定要偷，仍然要和“不偷当前”的收益比较；
- 空数组：题目通常不提供，但空间压缩版本可以自然返回 `0`；
- 当前代码的空数组会返回 `undefined`，如果要兼容空数组，需要先判断 `nums.length === 0`，或改用空间压缩版本。

时间复杂度：`O(n)`。

空间复杂度：当前 `result` 数组版本为 `O(n)`；空间压缩版本为 `O(1)`。

不能偷窃相邻房屋，求从给定金额中可获得的最大总金额。

#### 示例 1

```text
nums = [1,2,3,1]
输出 = 4
```

```text
nums = [2,7,9,3,1]
输出 = 12
```

- 0

- 只需保留前两个状态。
