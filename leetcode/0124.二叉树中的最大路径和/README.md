## 题目说明（本地训练版）

求二叉树中任意非空节点路径的最大节点值之和。

### 官方示例

#### 示例 1

```text
root = [1,2,3]
输出 = 6
```

#### 示例 2

```text
root = [-10,9,20,null,null,15,7]
输出 = 42
```

### 约束与训练提示

- 树中节点数目范围是 [1, 3 * 10^4]
- -1000 <= Node.val <= 1000
- 路径不必经过根节点。
- 向父节点返回时只能选择左右一条分支。
