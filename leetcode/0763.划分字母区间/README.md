# [763. 划分字母区间](https://leetcode.cn/problems/partition-labels/)

## 解题思路

你的整体思路是正确的，可以规范成两步：

```text
第一遍：记录每个字符最后一次出现的位置
第二遍：根据这些最后位置确定每个片段的边界
```

题目要求同一个字符不能出现在两个片段中。因此，一个片段如果包含字符 `c`，就必须至少延伸到 `c` 最后出现的位置。

### 1. 第一次遍历：记录最后出现位置

```js
const last = new Map()

for (let i = 0; i < s.length; i++) {
  last.set(s[i], i)
}
```

同一个字符重复出现时，后面的位置会覆盖前面的位置，因此最后留下的就是最晚下标。

例如：

```text
s = "ababcbaca"
a -> 8
b -> 5
c -> 7
```

### 2. 第二次遍历：维护当前片段的最远边界

```js
let start = 0
let end = 0
```

其中：

```text
start：当前片段的起始下标
end：当前片段必须覆盖到的最远下标
```

遍历到 `s[i]` 时：

```js
end = Math.max(end, last.get(s[i]))
```

当前片段中又出现了一个字符，片段边界至少要延伸到它最后出现的位置。不能直接把 `end` 覆盖成新的最后位置，因为前面字符可能已经要求更远的边界。

当：

```js
i === end
```

说明当前片段已经扫描到了它要求的最远位置，当前片段中的每个字符最后一次出现都在片段内部，可以安全切分：

```js
result.push(end - start + 1)
start = end + 1
```

### 3. 为什么这是贪心

从左向右构建片段时，能在最早的位置切分就立即切分。但只要当前片段中的某个字符还会在后面出现，就必须继续延伸边界。

当 `i === end` 时，已经没有理由继续向后延伸，因此得到当前能够形成的最短合法片段，也就能得到尽可能多的片段。

## 核心不变量

遍历到下标 `i` 时：

```text
end 是当前片段中所有已扫描字符的最后出现位置中的最大值。
```

因此：

- `i < end`：当前片段还不能切分；
- `i === end`：当前片段可以安全切分；
- 切分后，下一段从 `end + 1` 开始。

## 边界条件

- 空字符串：返回 `[]`；
- 单个字符：返回 `[1]`；
- 每个字符只出现一次：每个字符都可以单独形成一个片段；
- 所有字符都相同：只能形成一个片段；
- 当前字符的最后位置小于已有 `end`：不能缩短当前片段边界；
- 当前字符的最后位置大于已有 `end`：必须扩展当前片段边界。

时间复杂度：`O(n)`，字符串被完整遍历两次。

空间复杂度：`O(k)`，`k` 是不同字符的数量；如果只考虑小写英文字母，辅助空间可以看作 `O(26)`。

## 题目说明（本地训练版）

将字符串分割成尽可能多的片段，使每个字符只出现在一个片段中。
解题时先记录所有字符的最后出现下标，再进行第二轮遍历；如果当前位置已经覆盖当前片段中所有字符的最晚出现位置，就可以切分。

### 官方示例

#### 示例 1

```text
s = "ababcbacadefegdehijhklij"
输出 = [9,7,8]
```

#### 示例 2

```text
s = "eccbbbbdec"
输出 = [10]
```

### 约束与训练提示

- 1 <= s.length <= 500
- s 仅由小写英文字母组成
- 需预先记录每个字符最后出现位置。
- 当扫描位置到达当前片段最远边界时完成分割。
