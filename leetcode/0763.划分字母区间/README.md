## 题目说明（本地训练版）

将字符串分割成尽可能多的片段，使每个字符只出现在一个片段中。

### 官方示例

#### 示例 1

```text
s = "ababcbacadefegdehijhklij"
输出 = [9,7,8]
```

#### 示例 2

```text
s = "eccbbbbdec"
输出 = [10]
```

### 约束与训练提示

- 1 <= s.length <= 500
- s 仅由小写英文字母组成
- 需预先记录每个字符最后出现位置。
- 当扫描位置到达当前片段最远边界时完成分割。
