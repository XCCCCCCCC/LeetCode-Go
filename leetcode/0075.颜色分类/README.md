## 题目说明（本地训练版）

原地将只包含 0、1、2 的数组按这三种值排序。

### 官方示例

#### 示例 1

```text
nums = [2,0,2,1,1,0]
输出 = [0,0,1,1,2,2]
```

#### 示例 2

```text
nums = [2,0,1]
输出 = [0,1,2]
```

### 约束与训练提示

- n == nums.length
- 1 <= n <= 300
- nums[i] 为 0、1 或 2
- 你能想出一个仅使用常数空间的一趟扫描算法吗？
- 不应直接调用通用排序函数作为目标解法。
- 荷兰国旗三指针可以单次遍历。
