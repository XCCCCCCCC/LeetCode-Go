## 题目说明（本地训练版）

返回二叉搜索树中按从小到大排列的第 k 个元素。

### 官方示例

#### 示例 1

```text
root = [3,1,4,null,2]
k = 1
输出 = 1
```

#### 示例 2

```text
root = [5,3,6,2,4,null,null,1]
k = 3
输出 = 3
```

### 约束与训练提示

- 树中的节点数为 n 。
- 1 <= k <= n <= 10^4
- 0 <= Node.val <= 10^4
- 二叉搜索树的中序遍历是升序序列。
- 找到第 k 个后可以提前停止。
