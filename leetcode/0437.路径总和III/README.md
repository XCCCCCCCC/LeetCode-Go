## 题目说明（本地训练版）

统计二叉树中节点值之和等于目标值的向下路径数量。

### 官方示例

#### 示例 1

```text
root = [10,5,-3,3,2,null,11,3,-2,null,1]
targetSum = 8
输出 = 3
```

#### 示例 2

```text
root = [5,4,8,11,null,13,4,7,2,null,null,5,1]
targetSum = 22
输出 = 3
```

### 约束与训练提示

- 二叉树的节点个数的范围是 [0,1000]
- -10^9
- -1000
- 路径可从任意节点开始和结束，但方向必须从父到子。
- 前缀和频次需在回溯时撤销。
