# [删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/)

给你一个 升序排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。

由于在某些语言中不能改变数组的长度，所以必须将结果放在数组nums的第一部分。更规范地说，如果在删除重复项之后有 k 个元素，那么 nums 的前 k 个元素应该保存最终结果。

将最终结果插入 nums 的前 k 个位置后返回 k 。

不要使用额外的空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。

判题标准：
系统会用下面的代码来测试你的题解：
```
int[] nums = [...]; // 输入数组
int[] expectedNums = [...]; // 长度正确的期望答案

int k = removeDuplicates(nums); // 调用

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
```

如果所有断言都通过，那么您的题解将被通过。

示例1：
```
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：函数应该返回新的长度 2 ，并且原数组 nums 的前两个元素被修改为 1, 2 。不需要考虑数组中超出新长度后面的元素。
```

示例2：
```
输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4]
解释：函数应该返回新的长度 5 ， 并且原数组 nums 的前五个元素被修改为 0, 1, 2, 3, 4 。不需要考虑数组中超出新长度后面的元素。
```

## 解题思路
**思路1**：简单题，注意循环过程中i的复位。
**思路2**：快慢指针，slow和fast两个指针。针对有序数组的特点，相同元素的下标一定是连续的。若数组长度为n，则fast指针从1至n-1开始遍历，如果fast和fast-1不想等，则将fast赋值给slow，slow++。遍历结束后返回slow即可。

## 模拟题变体：每个元素最多出现两次

### 题目变化

原题要求每个数字只保留一次；变体允许每个数字最多保留两次。

数组已经有序，因此相同数字一定连续出现。仍然可以使用快慢指针原地覆盖：

- `fast`：扫描原数组。
- `slow`：指向下一个写入位置。
- `nums[0...slow - 1]`：已经整理好的有效结果。

### 为什么从下标 2 开始

任何数字的前两次出现都允许保留，所以长度不超过 2 时直接返回原长度；数组更长时，前两个元素可以先保留：

```js
let slow = 2
```

`fast` 也从第三个元素开始判断。

### 为什么比较 `slow - 2`

判断当前数字 `nums[fast]` 能否写入时，将它与有效结果中倒数第二个元素比较：

```js
nums[fast] !== nums[slow - 2]
```

- 如果相等，说明有效结果末尾已经存在两个相同数字，当前数字是第三次或更多次出现，跳过。
- 如果不同，说明当前数字在有效结果中还不足两次，可以写入。

每保留一个元素，只写入一次，`slow` 也只增加一次：

```js
nums[slow] = nums[fast]
slow++
```

### 完整写法

```js
var removeDuplicatesAtMostTwice = function (nums) {
  if (nums.length <= 2) {
    return nums.length
  }

  let slow = 2

  for (let fast = 2; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow - 2]) {
      nums[slow] = nums[fast]
      slow++
    }
  }

  return slow
}
```

### 流程示例

输入：

```text
[1,1,1,2,2,3]
```

前两个元素先保留，初始 `slow = 2`：

```text
fast 指向第三个 1：与有效结果倒数第二个 1 相同，跳过
fast 指向第一个 2：与有效结果倒数第二个 1 不同，写入
fast 指向第二个 2：与有效结果倒数第二个 1 不同，写入
fast 指向 3：与有效结果倒数第二个 2 不同，写入
```

最终有效部分：

```text
[1,1,2,2,3]
```

返回新长度 `5`。

### 本次易错点

- 不能只判断 `nums[fast - 1] !== nums[fast]`，那只能识别是否遇到了新数字，无法保留第二次出现。
- 不能在遇到新数字时让 `slow` 连续增加两次；数组中的每个元素都应该独立接受一次判断。
- `slow` 表示有效结果的长度，同时也是下一个写入位置。
- `slow - 2` 检查的是已经整理好的结果，而不是尚未处理完的原数组。
- 该方法依赖数组有序；无序数组中相同数字不连续，不能直接使用这个判断。

### 复杂度

- 时间复杂度：`O(n)`，每个元素扫描一次。
- 空间复杂度：`O(1)`，直接在原数组上覆盖。
