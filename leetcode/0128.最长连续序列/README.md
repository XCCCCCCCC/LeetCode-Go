# [128. Longest Consecutive Sequence](https://leetcode.cn/problems/longest-consecutive-sequence/description/)

## 题目

给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1：

输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
示例 2：

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
示例 3：

输入：nums = [1,0,1,2]
输出：3

提示：

0 <= nums.length <= 105
-109 <= nums[i] <= 109

## 解题思路

当前推荐版本 `longestConsecutive2` 使用 `Set` 去重。对每个数字 `num`，只有在 `num - 1` 不存在时，才把它视为一段连续序列的起点，然后向右探测 `num + 1、num + 2...`。

核心不变量：每个连续序列只从最小值启动；因此虽然有 `for` 嵌套 `while`，每个数字最多被连续探测一次，平均时间复杂度为 O(n)，空间复杂度为 O(n)。`longestConsecutive1` 的排序版更直观，但复杂度是 O(n log n)。

## 边界条件

- 空数组。
- 只有一个元素。
- 包含重复数字。
- 连续序列不按顺序出现。
- 空数组应返回 0；重复数字只计数一次。
