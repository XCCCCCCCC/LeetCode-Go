## 题目说明（本地训练版）

只允许一次买入和一次之后的卖出，求可获得的最大利润。

### 官方示例

#### 示例 1

```text
prices = [7,1,5,3,6,4]
输出 = 5
```

#### 示例 2

```text
prices = [7,6,4,3,1]
输出 = 0
```

### 约束与训练提示

- 1
- 0
- 买入必须发生在卖出之前。
- 无法盈利时返回零。
