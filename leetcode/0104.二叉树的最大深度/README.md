## 题目说明（本地训练版）

计算二叉树从根节点到最远叶子节点的最大节点数。

### 官方示例

#### 示例 1

```text
root = [3,9,20,null,null,15,7]
输出 = 3
```

#### 示例 2

```text
root = [1,null,2]
输出 = 2
```

### 约束与训练提示

- 树中节点的数量在 [0, 10^4] 区间内。
- -100 <= Node.val <= 100
- 空树深度为零。
- 递归返回左右子树较大深度加一。
