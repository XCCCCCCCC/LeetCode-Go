## 题目说明（本地训练版）

求和最大的非空连续子数组及其和。

### 官方示例

#### 示例 1

```text
nums = [-2,1,-3,4,-1,2,1,-5,4]
输出 = 6
```

#### 示例 2

```text
nums = [1]
输出 = 1
```

#### 示例 3

```text
nums = [5,4,-1,7,8]
输出 = 23
```

### 约束与训练提示

- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
- 输入可能全为负数。
- 状态需区分“以当前位置结尾”和全局最优值。
