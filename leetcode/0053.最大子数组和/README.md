# [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

## 解题思路

### 思路一：双重循环累加

`maxSubArray_func1` 是容易理解的暴力版本：外层固定起点 `i`，内层不断向右扩展终点 `j`，用 `sum += nums[j]` 维护区间 `[i, j]` 的和，并实时更新最大值。这样可以枚举所有非空连续子数组，也能正确处理全负数和混合正负数。

核心不变量：进入每次内层循环时，`sum` 恰好等于当前起点 `i` 到终点 `j` 的连续子数组和。

时间复杂度为 O(n²)，空间复杂度为 O(1)。它适合用来验证题意，但题目数据规模较大时会超时。

### 思路二：Kadane 动态规划

将问题拆成 `n` 个小问题：

> `dp[i]` 表示“必须以 `nums[i]` 结尾的最大连续子数组和”。

当处理 `nums[i]` 时，只有两种选择：

1. 抛弃之前的区间，从 `nums[i]` 重新开始；
2. 把 `nums[i]` 接在前一个位置的最优区间后面。

因此状态转移为：

```
dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

如果 `dp[i - 1]` 小于或等于 0，接上它只会让当前结果更差或不变，因此可以舍弃；`max` 判断把这两种选择统一起来。完成所有 `dp[i]` 的计算后，再取所有状态中的最大值。

当前 `maxSubArray_func2` 用 `pre` 保存上一个状态，用 `max` 保存全局最优值，不需要保存完整的 `dp` 数组：

```js
let max = nums[0]
let pre = nums[0]

for (let i = 1; i < nums.length; i++) {
  pre = Math.max(pre + nums[i], nums[i])
  max = Math.max(max, pre)
}
```

因此优化后时间复杂度为 O(n)，空间复杂度为 O(1)。

## 边界条件

- 空数组不属于题目约束；当前代码对空数组返回 `undefined`。
- 全负数组必须返回最大的单个元素，例如 `[-3,-1,-2]` 返回 `-1`。

## 题目说明（本地训练版）

求和最大的非空连续子数组及其和。

### 官方示例

#### 示例 1

```text
nums = [-2,1,-3,4,-1,2,1,-5,4]
输出 = 6
```

#### 示例 2

```text
nums = [1]
输出 = 1
```

#### 示例 3

```text
nums = [5,4,-1,7,8]
输出 = 23
```

### 约束与训练提示

- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
- 输入可能全为负数。
- 状态需区分“以当前位置结尾”和全局最优值。
