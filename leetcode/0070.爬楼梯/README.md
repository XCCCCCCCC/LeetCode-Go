每次可上一阶或两阶，计算到达第 n 阶的不同方式数。

### 官方示例

#### 示例 1

```text
n = 2

```

#### 示例 2


### 约束与训练提示

- 1 <= n <= 45
- 当前阶的方案数来自前一阶和前两阶。
- 可将空间压缩为两个变量。
