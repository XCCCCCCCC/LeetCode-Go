## 题目说明（本地训练版）

交换二叉树每个节点的左右子树，返回翻转后的根节点。

### 官方示例

#### 示例 1

```text
root = [4,2,7,1,3,6,9]
输出 = [4,7,2,9,6,3,1]
```

#### 示例 2

```text
root = [2,1,3]
输出 = [2,3,1]
```

#### 示例 3

```text
root = []
输出 = []
```

### 约束与训练提示

- 树中节点数目范围在 [0, 100] 内
- -100 <= Node.val <= 100
- 每个非空节点都需要交换左右孩子。
- 递归和层序遍历均可实现。
