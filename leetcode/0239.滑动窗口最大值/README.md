## 题目说明（本地训练版）

对每个固定长度的滑动窗口，输出窗口内的最大值。

### 官方示例

#### 示例 1

```text
nums = [1,3,-1,-3,5,3,6,7]
k = 3
输出 = [3,3,5,5,6,7]
```

#### 示例 2

```text
nums = [1]
k = 1
输出 = [1]
```

### 约束与训练提示

- 窗口每次向右移动一位。
- 单调队列中应保存下标以判断元素是否过期。
