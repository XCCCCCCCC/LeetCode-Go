## 题目说明（本地训练版）

实现固定容量的最近最少使用缓存，支持查询和写入。

### 官方示例

#### 示例 1

```text
operations = ["LRUCache","put","put","get","put","get","put","get","get","get"]
arguments = [[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3],[4]]
输出 = [null,null,null,1,null,-1,null,-1,3,4]
```

### 约束与训练提示

- 1 <= capacity <= 3000
- 0 <= key <= 10000
- 0 <= value <= 10^5
- 最多调用 2 * 10^5 次 get 和 put
- get 与 put 的平均时间复杂度应为 O(1)。
- 容量超限时淘汰最久未被访问的键。
