# [48. 旋转图像](https://leetcode.cn/problems/rotate-image/)

## 解题思路

题目要求顺时针旋转 90 度，并且必须原地修改矩阵，不能新建同尺寸矩阵。因此可以把旋转拆成两次简单的对称变换。

## 先统一翻转术语

为了避免“水平翻转”和“垂直翻转”的歧义，这份笔记统一使用方向描述：

| 说法 | 操作 | 几何含义 |
|---|---|---|
| 左右翻转 | 每一行从左到右反转 | 关于垂直中轴线对称 |
| 上下翻转 | 交换第一行和最后一行 | 关于水平中轴线对称 |
| 主对角线转置 | `matrix[i][j] <-> matrix[j][i]` | 关于左上到右下对角线对称 |
| 副对角线转置 | `matrix[i][j] <-> matrix[n-j-1][n-i-1]` | 关于右上到左下对角线对称 |

不同资料可能把“左右翻转”称为“水平翻转”，也可能把“绕垂直轴翻转”称为“垂直翻转”。做题时以具体下标操作为准，不要只记名称。

### `rotate_func1`：左右翻转 + 副对角线对称

第一步，左右翻转每一行，也就是关于垂直中轴线对称：

```text
[1,2,3]       [3,2,1]
[4,5,6]  ->   [6,5,4]
[7,8,9]       [9,8,7]
```

第二步，沿副对角线交换：

```text
matrix[i][j] <-> matrix[n-j-1][n-i-1]
```

副对角线是从右上角到左下角的线。为了每一对元素只交换一次，`j` 的范围需要随着 `i` 缩小：

```js
let corner = n - 1

for (let i = 0; i < n - 1; i++) {
  for (let j = 0; j < corner; j++) {
    // 交换副对角线两侧的元素
  }
  corner--
}
```

这个版本的关键是 `corner` 必须定义在外层循环之前，不能每次进入外层循环时重新初始化。

### `rotate_func2`：主对角线转置 + 左右翻转

这是更常见、也更容易复现的写法。

第一步，沿主对角线转置，只交换右上三角：

```js
for (let i = 0; i < n; i++) {
  for (let j = i + 1; j < n; j++) {
    // 交换 matrix[i][j] 和 matrix[j][i]
  }
}
```

之所以从 `j = i + 1` 开始，是因为：

- 主对角线上的元素不需要移动；
- 左下三角与右上三角是对称位置，只交换一侧即可；
- 避免同一对元素被交换两次。

第二步，将每一行左右翻转，也就是关于垂直中轴线对称：

```text
原矩阵：       转置后：       每行翻转后：
1 2 3          1 4 7          7 4 1
4 5 6    ->    2 5 8    ->    8 5 2
7 8 9          3 6 9          9 6 3
```

### 两种方案的关系

两种方案都能完成顺时针旋转：

```text
func1：左右翻转 + 副对角线对称
func2：主对角线转置 + 左右翻转
```

推荐把 `rotate_func2` 作为最终提交版本，因为主对角线转置的交换关系更直观：

```text
(i, j) <-> (j, i)
```

核心不变量：每次交换都只处理一对尚未完成位置，且不创建新的矩阵；两次变换完成后，每个元素都到达顺时针旋转 90 度后的目标位置。

## 边界条件

- `1 × 1` 矩阵：不需要交换。
- `2 × 2` 矩阵：最适合手动验证四个元素的位置变化。
- 奇数阶矩阵：中心元素保持不动。
- 偶数阶矩阵：没有单独的中心元素，但交换边界不能越界。
- 不能使用 `matrix = matrix.map(...)` 创建新矩阵来代替原地修改。

## 题目说明（本地训练版）

将方形矩阵原地顺时针旋转九十度。

### 官方示例

#### 示例 1

```text
matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出 = [[7,4,1],[8,5,2],[9,6,3]]
```

#### 示例 2

```text
matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出 = [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

### 约束与训练提示

- n == matrix.length == matrix[i].length
- 1 <= n <= 20
- -1000 <= matrix[i][j] <= 1000
- 不能通过新建同尺寸矩阵作为最终解法。
- 可将旋转拆成转置与翻转。
