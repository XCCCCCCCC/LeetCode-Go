## 题目说明（本地训练版）

反转一条单链表并返回新的头节点。

### 官方示例

#### 示例 1

```text
head = [1,2,3,4,5]
输出 = [5,4,3,2,1]
```

#### 示例 2

```text
head = [1,2]
输出 = [2,1]
```

#### 示例 3

```text
head = []
输出 = []
```

### 约束与训练提示

- 链表中节点的数目范围是 [0, 5000]
- -5000
- 更改 next 之前必须保存原后继节点。
- 空链表和单节点链表应直接返回。
