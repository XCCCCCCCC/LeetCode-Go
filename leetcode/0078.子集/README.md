# [78. 子集](https://leetcode.cn/problems/subsets/)

## 解题思路

### 先明确：子集和全排列哪里不同

全排列与子集都可以使用回溯，但它们对“顺序”的要求不同：

```text
全排列：[1,2] 和 [2,1] 是两个不同答案
子集：  [1,2] 和 [2,1] 是同一个答案
```

因此，全排列每一层都可以重新查看整个 `nums`，只要跳过已经使用的数字即可；子集则不能回头选择，否则会生成顺序不同、内容相同的重复答案。

例如，如果仍然让每层从 `0` 开始，`nums = [1,2]` 会得到：

```text
[]
[1]
[1,2]
[2]
[2,1]  // 和 [1,2] 是同一个子集，重复了
```

所以这道题不能只使用：

```js
temp.includes(nums[i])
```

它只能防止同一条路径重复使用同一个数字，却不能防止 `[1,2]` 和 `[2,1]` 同时出现。

### 子集题真正需要的边界：`start`

需要给回溯函数传入一个 `start`，表示：

> 下一次选择只能从下标 `start` 开始，前面的下标不再考虑。

```js
function backTrack(start) {
  result.push([...temp])

  for (let i = start; i < nums.length; i++) {
    temp.push(nums[i])
    backTrack(i + 1)
    temp.pop()
  }
}
```

假设当前选择了 `nums[i]`，下一层执行：

```js
backTrack(i + 1)
```

表示以后只能选择它右边的数字。

以 `[1,2,3]` 为例：

```text
选择 1 后，可以继续选择 2、3
选择 2 后，只能继续选择 3
选择 3 后，右边没有数字，当前分支自然结束
```

这样可以生成：

```text
[1,2]
```

但不会再生成：

```text
[2,1]
```

因为从 `2` 开始后，只能向右选择 `3`，不能回头选择 `1`。

### 为什么这里不再需要 `includes`

`start` 保证下标只能一直向右移动：

```text
0 → 1 → 2
```

已经选择过的下标位于当前位置左侧，下一层不会再访问它，所以同一个数字不可能在一条路径中被重复选择。

因此加入 `start` 后，可以删除：

```js
if (temp.includes(nums[i])) {
  continue
}
```

全排列使用 `used`，子集使用 `start`，可以先这样区分：

```text
全排列：每个位置都能从所有数字中选，但不能重复使用 → used
子集：为了避免顺序重复，只允许向右选 → start
```

### 最难想到的边界：什么时候保存答案

全排列只有长度达到 `nums.length` 时才是完整答案：

```js
if (path.length === nums.length) {
  result.push([...path])
  return
}
```

但子集的长度可以是任意长度：

```text
长度 0：[]
长度 1：[1]、[2]、[3]
长度 2：[1,2]、[1,3]、[2,3]
长度 3：[1,2,3]
```

也就是说，搜索过程中的每一个 `temp` 都是合法答案，而不只是最深处的路径。

所以进入每一层回溯时，第一件事就是记录当前路径：

```js
result.push([...temp])
```

第一次调用：

```js
backTrack(0)
```

此时 `temp = []`，因此空集也会被自动记录，不需要单独执行：

```js
result.push([])
```

### 为什么没有明确的递归终止条件

这也是子集题最容易困惑的地方。代码中似乎没有：

```js
if (...) return
```

但它仍然会结束，因为 `for` 循环本身就是边界。

例如选择最后一个数字 `3` 后：

```js
backTrack(3)
```

而数组长度也是 `3`：

```js
for (let i = 3; i < 3; i++) {
  // 条件一开始就是 false，循环不会执行
}
```

这一层函数执行完毕后自然返回上一层。因此：

```text
显式终止条件：没有
自然终止条件：start === nums.length 时，没有数字可以继续选择
```

当然也可以写：

```js
if (start === nums.length) {
  return
}
```

但它是多余的，因为后面的循环本来就不会执行。

### 推荐写法

```js
var subsets = function (nums) {
  const result = []
  const temp = []

  function backTrack(start) {
    result.push([...temp])

    for (let i = start; i < nums.length; i++) {
      temp.push(nums[i])
      backTrack(i + 1)
      temp.pop()
    }
  }

  backTrack(0)
  return result
}
```

当前实现已经采用这套写法：

```js
function backTrack(start) {
  result.push([...temp])

  for (let i = start; i < nums.length; i++) {
    temp.push(nums[i])
    backTrack(i + 1)
    temp.pop()
  }
}
```

代码中的三个关键点分别对应：

```text
result.push([...temp])：每个中间路径都是一个合法子集
for (let i = start; ...)：本层只能从允许的右侧范围选择
backTrack(i + 1)：下一层不回头，避免生成顺序重复
```

仍然按照机考的五个问题分析：

```text
path：temp，当前已经选择的数字
choice：从 start 到 nums.length - 1 的数字
invalid：不需要额外判断，start 已经排除了左侧数字
finish：每一个 temp 都是答案，进入递归就保存
restore：递归返回后 temp.pop()
```

### 用 `[1,2,3]` 跟踪一条路径

```text
backTrack(0)，temp = []
保存 []

选择 nums[0] = 1
temp = [1]
进入 backTrack(1)
保存 [1]

  选择 nums[1] = 2
  temp = [1,2]
  进入 backTrack(2)
  保存 [1,2]

    选择 nums[2] = 3
    temp = [1,2,3]
    进入 backTrack(3)
    保存 [1,2,3]

    start = 3，没有选择，自动返回
    撤销 3，temp = [1,2]

  当前循环结束，返回
  撤销 2，temp = [1]

  改选 nums[2] = 3
  得到并保存 [1,3]
```

以 `1` 开头的分支完成后，根节点会继续选择 `2`，得到 `[2]`、`[2,3]`，最后选择 `3` 得到 `[3]`。

完整结果共有：

```text
[]
[1] [2] [3]
[1,2] [1,3] [2,3]
[1,2,3]
```

### 为什么有 `2^n` 个子集

每个数字都有两个选择：

```text
选它
不选它
```

`n` 个数字各自有两种状态，所以一共有：

```text
2 × 2 × ... × 2 = 2^n
```

例如三个数字：

```text
2^3 = 8
```

因此复杂度为：

```text
时间复杂度：O(n × 2^n)
结果空间：O(n × 2^n)
额外空间：O(n)
```

`2^n` 是子集数量，每次保存答案时复制数组最多需要 `O(n)`。

### 和 46 全排列放在一起记

| 对比项 | 46 全排列 | 78 子集 |
|---|---|---|
| 顺序是否重要 | 重要 | 不重要 |
| 每层从哪里选 | 从整个数组选择未使用数字 | 从 `start` 开始向右选择 |
| 防止重复的方法 | `used[i]` | `start` |
| 何时保存答案 | 路径长度等于 `n` | 每次进入递归都保存 |
| 是否显式终止 | 通常需要 | 通常不需要，循环自然结束 |

机考时可以先用这句话区分：

```text
排列要换顺序，所以每层从头选；
子集不看顺序，所以只能向右选。
```

核心不变量：每次进入 `backTrack(start)` 时，`temp` 已经是一个合法且下标严格递增的子集；下一步只能选择 `start` 及其右侧元素，因此不会生成顺序不同的重复子集。

## 边界条件

- 空集必须存在：第一次执行 `backTrack(0)` 时自动保存 `[]`。
- 数组本身必须存在：一路选择所有数字即可得到完整数组。
- 单元素数组：结果为 `[]` 和包含该元素的子集。
- `start === nums.length`：没有后续选择，函数自然返回。
- 输入元素互不相同，因此不需要处理输入本身的重复值。
- 保存答案时必须复制 `temp`，不能直接保存同一个数组引用。
- 下一层必须传 `i + 1`，如果仍传 `start` 或 `i`，可能产生重复选择或无限递归。

## 题目说明（本地训练版）

返回不含重复元素的数组的幂集。

### 官方示例

#### 示例 1

```text
nums = [1,2,3]
输出 = [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

#### 示例 2

```text
nums = [0]
输出 = [[],[0]]
```

### 约束与训练提示

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10
- nums 中的所有元素 互不相同
- 结果必须包含空集和数组本身。
- 为避免重复子集，下一层只从当前位置之后选择。
