## 题目说明（本地训练版）

返回不含重复元素的数组的幂集。

### 官方示例

#### 示例 1

```text
nums = [1,2,3]
输出 = [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

#### 示例 2

```text
nums = [0]
输出 = [[],[0]]
```

### 约束与训练提示

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10
- nums 中的所有元素 互不相同
- 结果必须包含空集和数组本身。
- 为避免重复子集，下一层只从当前位置之后选择。
