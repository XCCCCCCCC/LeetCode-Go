## 题目说明（本地训练版）

机器人只能向右或向下移动，计算从网格左上角到右下角的不同路径数。

### 官方示例

#### 示例 1

```text
m = 3
n = 7
输出 = 28
```

#### 示例 2

```text
m = 3
n = 2
输出 = 3
```

#### 示例 3

```text
m = 7
n = 3
输出 = 28
```

#### 示例 4

```text
m = 3
n = 3
输出 = 6
```

### 约束与训练提示

- 1 <= m, n <= 100
- 题目数据保证答案小于等于 2 * 10^9
- 每个格子的路径数来自上方和左方之和。
- 第一行和第一列的路径数均为一。
