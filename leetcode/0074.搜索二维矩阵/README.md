## 题目说明（本地训练版）

在每行升序且下一行首元素大于上一行末元素的矩阵中查找目标值。

### 官方示例

#### 示例 1

```text
matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]
target = 3
输出 = true
```

#### 示例 2

```text
matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]
target = 13
输出 = false
```

### 约束与训练提示

- m == matrix.length
- n == matrix[i].length
- 1 <= m, n <= 100
- -10^4 <= matrix[i][j], target <= 10^4
- 可将矩阵视为一个虚拟升序一维数组。
- 需通过整除和取模将一维下标还原为行列。
