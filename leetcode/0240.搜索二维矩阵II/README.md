## 题目说明（本地训练版）

在每行、每列均递增的矩阵中判断目标值是否存在。

### 官方示例

#### 示例 1

```text
matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]
target = 5
输出 = true
```

#### 示例 2

```text
matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]
target = 20
输出 = false
```

### 约束与训练提示

- m == matrix.length
- n == matrix[i].length
- 1 <= n, m <= 300
- -10^9 <= matrix[i][j] <= 10^9
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- -10^9 <= target <= 10^9
- 从右上或左下角出发可每次排除一行或一列。
- 空矩阵需要单独处理。
