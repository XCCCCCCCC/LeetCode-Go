# [240. 搜索二维矩阵 II](https://leetcode.cn/problems/search-a-2d-matrix-ii/)

## 解题思路

矩阵的每一行从左到右递增，每一列从上到下递增。选择右上角作为起点，是因为这个位置同时具有两个方向不同的大小关系：

```text
向左：数值变小
向下：数值变大
```

设当前位置为 `matrix[row][column]`：

1. 当前值等于 `target`，直接返回 `true`；
2. 当前值小于 `target`，当前行左侧的值只会更小，因此整行都不可能包含目标，执行 `row++`；
3. 当前值大于 `target`，当前列下方的值只会更大，因此整列都不可能包含目标，执行 `column--`。

可以记成：

```text
当前值太小：向下找更大的值
当前值太大：向左找更小的值
```

以查找 `5` 为例，路径可能是：

```text
15 > 5，向左
11 > 5，向左
7  > 5，向左
4  < 5，向下
5 == 5，找到
```

核心不变量：每轮循环开始时，答案如果存在，只可能位于 `row` 到最后一行、第一列到 `column` 所围成的候选区域；每次移动都会安全排除一整行或一整列。

`row` 最多向下移动 `m` 次，`column` 最多向左移动 `n` 次，因此：

```text
时间复杂度：O(m + n)
空间复杂度：O(1)
```

## 边界条件

- 单行矩阵：只能持续向左移动或找到后返回。
- 单列矩阵：只能持续向下移动或找到后返回。
- 目标小于矩阵最小值：最终从左边界离开。
- 目标大于矩阵最大值：最终从下边界离开。
- 目标位于左上角或右下角：移动方向仍然有效。
- 当前题目约束保证矩阵非空；若用于通用代码，可以先判断 `matrix.length` 和 `matrix[0].length`。

## 题目说明（本地训练版）

在每行、每列均递增的矩阵中判断目标值是否存在。

### 官方示例

#### 示例 1

```text
matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]
target = 5
输出 = true
```

#### 示例 2

```text
matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]
target = 20
输出 = false
```

### 约束与训练提示

- m == matrix.length
- n == matrix[i].length
- 1 <= n, m <= 300
- -10^9 <= matrix[i][j] <= 10^9
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- -10^9 <= target <= 10^9
- 从右上或左下角出发可每次排除一行或一列。
- 空矩阵需要单独处理。
