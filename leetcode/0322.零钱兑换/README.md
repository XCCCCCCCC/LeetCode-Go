## 题目说明（本地训练版）

使用可重复选择的硬币凑出目标金额，求最少硬币数，无法凑出时返回 -1。

### 官方示例

#### 示例 1

```text
coins = [1,2,5]
amount = 11
输出 = 3
```

#### 示例 2

```text
coins = [2]
amount = 3
输出 = -1
```

#### 示例 3

```text
coins = [1]
amount = 0
输出 = 0
```

### 约束与训练提示

- 1 <= coins.length <= 12
- 1 <= coins[i] <= 2^31 - 1
- 0 <= amount <= 10^4
- 硬币可以使用任意次。
- 初始化值需能区分“尚不可达”与有效答案。
