## 题目说明（本地训练版）

模拟腐烂水果每分钟向四个方向扩散，求所有新鲜水果腐烂的最短时间。

### 官方示例

#### 示例 1

```text
grid = [[2,1,1],[1,1,0],[0,1,1]]
输出 = 4
```

#### 示例 2

```text
grid = [[2,1,1],[0,1,1],[1,0,1]]
输出 = -1
```

#### 示例 3

```text
grid = [[0,2]]
输出 = 0
```

### 约束与训练提示

- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 10
- grid[i][j] 仅为 0、1 或 2
- 初始腐烂水果应同时作为 BFS 起点。
- 若最终仍有新鲜水果则返回 -1。
