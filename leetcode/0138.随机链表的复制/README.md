## 题目说明（本地训练版）

深拷贝一条除 next 外还含 random 指针的链表。

### 官方示例

#### 示例 1

```text
head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出 = [[7,null],[13,0],[11,4],[10,2],[1,0]]
```

#### 示例 2

```text
head = [[1,1],[2,1]]
输出 = [[1,1],[2,1]]
```

#### 示例 3

```text
head = [[3,null],[3,0],[3,null]]
输出 = [[3,null],[3,0],[3,null]]
```

### 约束与训练提示

- 0 <= n <= 1000
- -10^4 <= Node.val <= 10^4
- Node.random 为 null 或指向链表中的节点。
- 新链表不能引用任何原链表节点。
- random 可以指向任意节点或空。
