# [279. 完全平方数](https://leetcode.cn/problems/perfect-squares/)

## 解题思路

你对这题的核心理解是正确的：

> 组成目标数时，枚举最后选用的那个完全平方数，再用已经算好的 `dp[目标 - 平方数]` 加 1，比较所有方案后取最小值。

### 1. 状态定义

```text
dp[i] = 组成数字 i 所需要的最少完全平方数个数
```

例如：

```text
dp[4] = 1，因为 4 = 4
dp[5] = 2，因为 5 = 4 + 1
dp[12] = 3，因为 12 = 4 + 4 + 4
```

### 2. 枚举最后一个平方数

组成 `i` 时，最后选用的完全平方数可以是 `1、4、9、16...`，但不能超过 `i`。

如果最后选择 `square`，前面还需要组成 `i - square`，这一种方案需要：

```text
dp[i - square] + 1
```

其中 `+1` 就是当前最后选用的这个平方数。

因此状态转移是：

```text
dp[i] = min(dp[i], dp[i - square] + 1)
```

这里的“最后一个”不是数组最后一位，而是某一种拆分方案中最后考虑、最后放入的完全平方数。

### 3. 初始化

```js
const dp = new Array(n + 1).fill(Infinity)
dp[0] = 0
```

`dp[0] = 0` 表示组成 0 不需要任何平方数，例如：

```text
dp[1] = dp[0] + 1 = 1
dp[4] = dp[0] + 1 = 1
```

其他位置先设为 `Infinity`，表示还没有找到方案，后续真实方案都可以正常把它更新为更小的值。

### 4. 你的代码逐行解释

外层循环依次计算 `dp[1]` 到 `dp[n]`；内层循环枚举所有不超过 `i` 的完全平方数：

```js
for (let i = 1; i <= n; i++) {
  for (let j = 1; j * j <= i; j++) {
    const square = j * j
    dp[i] = Math.min(dp[i], dp[i - square] + 1)
  }
}
```

`j * j <= i` 保证当前平方数不会超过目标 `i`。

### 5. 用 `n = 5` 走一遍

计算 `dp[5]` 时，最后一个平方数有两种可能：

```text
最后放 1：dp[4] + 1 = 1 + 1 = 2
最后放 4：dp[1] + 1 = 1 + 1 = 2
```

所以：

```text
dp[5] = 2
```

对应拆分是 `4 + 1`。

## 动态规划视角

这题的过程是：

```text
大问题：组成 i
小问题：组成 i - square
当前选择：再加一个 square
目标：所有选择中数量最少
```

因为更小数字的答案会被多个更大数字重复使用，所以先算出并保存它们，就不需要每次重新枚举完整拆分方案。

## 核心不变量

计算 `dp[i]` 时：

```text
dp[i] 保存当前已经尝试过的平方数方案中的最小数量
dp[i - square] 已经提前计算完成
```

内层循环结束后，`dp[i]` 就是组成 `i` 的全局最少平方数数量。

## 边界条件

- `n = 1`：`1 = 1`，返回 `1`；
- `n` 本身是完全平方数：返回 `1`；
- `n = 0`：如果题目允许，答案是 `0`；
- `dp[0]` 必须初始化为 `0`；
- 其他状态初始化为 `Infinity`。

时间复杂度：`O(n√n)`。

空间复杂度：`O(n)`。
