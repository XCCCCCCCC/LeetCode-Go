## 题目说明（本地训练版）

返回二叉树的中序遍历序列。

### 官方示例

#### 示例 1

```text
root = [1,null,2,3]
输出 = [1,3,2]
```

#### 示例 2

```text
root = []
输出 = []
```

#### 示例 3

```text
root = [1]
输出 = [1]
```

### 约束与训练提示

- 树中节点数目在范围 [0, 100] 内
- -100 <= Node.val <= 100
- 中序顺序为左子树、当前节点、右子树。
- 可使用递归或显式栈。
