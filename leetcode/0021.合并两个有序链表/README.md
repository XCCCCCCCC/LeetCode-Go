# [合并两个有序链表](https://developers.weixin.qq.com/miniprogram/dev/api/network/request/RequestTask.onHeadersReceived.html)

将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

示例1：
```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

示例2：
```
输入：l1 = [], l2 = []
输出：[]
```

示例3：
```
输入：l1 = [], l2 = [0]
输出：[0]
```

## 解题思路
**思路1**：迭代
**思路2**：递归

## 题目说明（本地训练版）

将两条升序链表合并为一条新的升序链表。

### 官方示例

#### 示例 1

```text
l1 = [1,2,4]
l2 = [1,3,4]
list1 = [1,2,4]
list2 = [1,3,4]
输出 = [1,1,2,3,4,4]
```

#### 示例 2

```text
l1 = []
l2 = []
list1 = []
list2 = []
输出 = []
```

#### 示例 3

```text
l1 = []
l2 = [0]
list1 = []
list2 = [0]
输出 = [0]
```

### 约束与训练提示

- 两个链表的节点数目范围是 [0, 50]
- -100
- l1 和 l2 均按 非递减顺序 排列
- 可复用原链表节点。
- 任意一条链表耗尽后直接连接另一条剩余部分。
