# [合并两个有序链表](https://developers.weixin.qq.com/miniprogram/dev/api/network/request/RequestTask.onHeadersReceived.html)

将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

示例1：
```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

示例2：
```
输入：l1 = [], l2 = []
输出：[]
```

示例3：
```
输入：l1 = [], l2 = [0]
输出：[0]
```
